# dsh-client-ui-dashboard

[DeepSeek Harness](https://github.com/deepseek-ai/deepseek-harness) 的实时会话看板。插件在「对话」「轨迹」旁增加「看板」，通过框架快照与投影读取数据，不另行请求模型或上传会话。

需要 **dsh 0.2.1-rc.3**（同一版本的 Web 内置插件），React 18。插件版本为 **0.4.0**。

## 界面与功能

| 分区 | 内容 |
| --- | --- |
| 会话概览 | 请求及状态、参考成本、平均首字延迟、解码速度；Token 构成、缓存命中、上下文压力和耗时分布 |
| 用量与性能 | 轮次耗时、工具调用与耗时排名、模型用量与时间线、消息角色、上下文来源、压缩与异常诊断 |
| 请求明细 | 状态筛选、搜索、分页、按轮次/模型/错误分组、展开详情、JSON 导出；趋势图按需展开 |
| 协作状态 | 当前会话的直接子代理、运行状态、打开子会话及归档 |

沿用 dsh 品牌色与明暗主题，统一线条图标和数字排版。概览展示真实请求耗时记录；性能页采用耗时主分析区与模型用量侧栏，工具按耗时排序并明确标注用户等待。轮次、消息构成和上下文来源合并为辅助信息带，诊断按需展开。看板与输入框独立占位，输入框增高时不会遮挡数据。窄屏表格可横向滚动，键盘焦点可见，减少动态效果的系统偏好生效。

## 数据口径

- 轮次、步骤、输入/输出 Token 和累计耗时优先来自全量日志投影；请求、工具、角色及诊断基于当前已加载窗口。顶部会提示还有更早历史未加载，缺失值显示 `—`。性能页的工具耗时仅累计有关联记录的调用，包含交互等待与并行调用，不代表会话实际时长。
- 轨迹目标为按需启用；看板通过官方 `useTrajectory` 订阅激活它，直接进入看板即可看到请求，无须先打开轨迹。
- 计费输入 = 未缓存输入 + 缓存命中 + 缓存写入。推理 Token 可能已包含在输出中，不加入堆叠条重复累加。
- 成本采用 [DeepSeek 官方峰时价格](https://api-docs.deepseek.com/quick_start/pricing/)（2026-10-26 核对）作参考，非历史账单。第三方路由、未知模型、未上报用量和进行中请求不套用官方单价；包含未计价请求时，总成本显示 `—` 并注明数量。
- 失败行原地展开错误；带有工具调用的请求可通过公开 `openView` 接口进入轨迹。没有可定位工具调用时，跳转按钮禁用，行仍可展开详情。
- 子代理状态来自会话目录；缺少完成信号时显示非运行状态，不把空闲推断为成功。结束时间只能近似估计，超过五分钟的条目归入默认折叠的归档。

## 从 npm 安装或升级

```sh
cd ~/.dsh/profiles/web
pnpm add dsh-client-ui-dashboard@0.4.0
```

首次安装还需添加下文的加载配置；升级时保留已有条目，重启 `dsh web` 并刷新页面。此命令会将原有本地链接切换为 npm 版本。

## 本地开发安装

在插件目录执行：

```sh
npm ci
npm run typecheck
npm test
npm run build
```

将已构建的目录链接进 Web profile：

```sh
cd ~/.dsh/profiles/web
pnpm add /绝对路径/dsh-tool-visual
```

在 `~/.dsh/profiles/web/cordis.patch.yml` 增加一次：

```yaml
- insert:
    - id: ui-dashboard
      name: dsh-client-ui-dashboard
```

重启 `dsh web` 并刷新浏览器。已有本地链接的安装只需重新构建、重启并刷新，不要重复插入配置。

## 开发

源码位于 `src/client`，宿主侧的工作流/提醒投影与 `board_query` 位于 `src/board`。`build.mjs` 生成 `lib/index.js`、浏览器模块 `lib/client.js` 以及声明文件；仓库随源码提交这些构建产物。开发依赖固定到已发布的 dsh 版本，不依赖相邻源码仓库的旧构建文件。

`npm test` 仅保留三个回归检查：请求适配和缺失数据、投影与子会话目录、直接打开看板及空投影渲染。真实页面另行验证筛选、展开、导航和窄屏布局。

指标派生主要成本是按请求排序，时间复杂度约为 O(n log n)，空间 O(n)，n 为已加载请求与事件数量；请求表分页，趋势最多绘制最近 60 个点。运行时每秒更新经过时间，停机时释放计时器。设计上下文位于 `.ui-craft/`。
