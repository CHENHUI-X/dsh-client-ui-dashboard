# DSH dashboard

A conversation-scoped observability surface for people using DeepSeek Harness. The first screen answers: is this session working, what is it consuming, and what needs inspection? Requests, model/tool analysis and child sessions each have a dedicated section. Preserve request filtering, grouped views, export, streaming, projection data, and navigation into the host trajectory.

Use the existing DSH brand accent and system typography. Follow host light/dark theme. Reduce repeated aggregates, empty charts, rainbow categories, tiny explanatory text and nested card borders. Primary request count has the strongest hierarchy. Details and methodology belong behind accessible disclosure or tooltips. No decorative entrance animation, remote fonts, new chart packages or fake data.
