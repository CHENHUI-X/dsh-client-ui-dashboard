# Dashboard tokens

DSH `--dsw-alias-*` variables own the theme. `--dshd-accent` maps to host business blue; surfaces inherit base and a 3% accent tint. Muted teal and indigo distinguish data series; errors retain host error red. Tool names share one hue rather than arbitrary rank colors.

System sans for text and metric values; host monospace only for identifiers and code. Type roles: 12px metadata, 13px body, 14px section, 20px title, 28px supporting metric, 42px primary metric. Numbers use tabular figures. Spacing uses 4/8/12/16/20/24/28px. Surfaces: 12px radius; controls: 6px; badges: 4px. Container breakpoints at 850px and 540px adapt to the actual conversation pane. Hover/focus transitions are brief; reduced-motion disables animations and transitions.
